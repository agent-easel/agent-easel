AgentEasel plans, starts and tracks multi-agent Runs. The agent work runs in T3 Code, so AgentEasel requires T3 Code. Start a Run from one prompt, let reusable Agents carry it through your Flow, and step in only when a decision needs you.

FEATURES

Your process, as a Flow you can run.

AgentEasel does not impose a development process. You decide the blocks and exits.

START

Start from one prompt

Describe the work in one focused box, pick the project and Flow, and paste or drop screenshots right into the prompt. Every worker receives the same original images.

  • Screenshots referenced inline
  • Run titles written for you
  • Drafts kept until you Start

DESIGN

Flows that branch, join and compose

Connect Agents, Human steps, Continuations and Waits with named exits and correction loops. Route by arrival with Conditions, synchronize parallel branches with Joins, nest saved Subflows and declare named Finish endings.

  • Subflows, Conditions, Joins & Finish endings
  • Continuations, Waits & correction loops
  • Readiness checks before Start

RUNS

Follow every Run at a glance

The canvas follows active blocks and highlights outgoing connections while one docked inspector shows progress, visits, pull requests and results. The timeline keeps key events up front.

  • Canvas follows active blocks & highlights connections
  • One docked inspector
  • Key events, full history on demand

DECISIONS

Read the result, then decide

Open any handoff as a formatted Markdown report with headings, code blocks and open questions. Answer Human steps in AgentEasel, or jump to the exact T3 Code thread when an agent asks.

  • Formatted Markdown result reports
  • Needs input and Problem states
  • Named Finish endings, Settle or Archive

AGENTS

Reuse and share Agents

Save a prompt, exits and worker settings once and reuse the Agent across Flows. Keep definitions global with per-project Worker overrides or owned by one Project, and share them as JSON.

  • Global & Project-owned definitions
  • Per-project Worker overrides
  • JSON import/export & immutable revisions

Works where you already work.

Start Runs from GitHub issues, your agent chat or Discord, let agents author Flows and Triggers, and tailor AgentEasel to your setup.

GitHub Issues Triggers

Start Runs automatically from open GitHub issues matching your query, up to a cap on active Runs, on a schedule or on demand.

Start from T3 Code

Ask the agent in a T3 Code conversation to start an AgentEasel Run through MCP, with the same readiness checks as New Run.

Agents author Flows & Triggers

AgentEasel MCP lets an agent create, edit, check and remove Agents, Flows and Triggers. Open Studio views refresh live.

Chat control on Discord

Start and follow Runs from Discord with live status cards, notices, listed bots and typed reply confirmation. Off until you turn it on.

Import and export

Share Agents and Flows as JSON files with optional model hints. Imports open for review before saving.

Custom color themes

Light and Dark modes with per-device JSON color themes compatible with T3 Code theme files, validated for readability.

Keyboard-first

Command palette, customizable shortcuts, a cheat sheet and a native macOS menu that stay in sync.

Guided setup & reporting

A one-time First-run setup connects T3 Code and installs AgentEasel MCP reporting for Claude, Codex, Cursor, Grok, Antigravity and Mistral Vibe.

Desktop notifications

Native notifications and a Dock badge count Runs that need your input or hit a Problem, without watching the window.

Built to run where your code lives.

Local-first

AgentEasel stores Flows, Agents and Run history on your machine. No cloud account.

Requires T3 Code

Agent work is carried out in T3 Code threads; AgentEasel routes the work.

Approved devices

Use the browser on the host, or approve a desktop or browser client over HTTPS.

Open source

MIT licensed. Try the simulated demo without T3 Code, credentials or paid model work.
